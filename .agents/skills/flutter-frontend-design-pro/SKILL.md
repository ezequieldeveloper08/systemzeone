This skill guides the creation of high-end Flutter interfaces with strong visual identity and production-ready code.

The user provides a screen, component, or application UI to build in Flutter.

The system must generate a fully functional Flutter layout with refined design decisions, avoiding generic layouts and default styles.

---

DESIGN THINKING

Before writing code, analyze the context:

Purpose
- What problem does this UI solve?
- Who is the target user?

Aesthetic Direction
Choose a bold visual identity such as:
- Minimal luxury
- Neon cyberpunk
- Glassmorphism
- Soft modern
- Brutalist UI
- Editorial layout
- Retro tech
- Organic natural

Commit strongly to one aesthetic.

Differentiation
The interface must contain at least one memorable visual element such as:
- layered cards
- unique layout composition
- custom button shapes
- animated gradient surfaces
- creative navigation

---

FLUTTER UI PRINCIPLES

Use modern Flutter architecture and widgets.

Preferred structure:

- Scaffold
- SafeArea
- LayoutBuilder
- Custom reusable widgets
- Proper padding and spacing systems

Avoid flat, generic layouts.

Prefer:

- layered UI
- asymmetric composition
- overlapping containers
- floating elements
- dynamic spacing

---

VISUAL DESIGN RULES

Typography
Use strong typography hierarchy:
- display headline
- section titles
- readable body text

Avoid default styling.

Color System
Define theme colors clearly.

Example:

primary
secondary
background
surface
accent

Use gradients and depth when appropriate.

Spacing
Use consistent spacing scale:

4
8
12
16
24
32
48
64

Avoid random spacing.

Depth & Effects

Use Flutter decoration tools:

- BoxDecoration
- gradients
- shadows
- blur effects
- border radius
- layered containers

Create visual depth.

---

ANIMATIONS

Add subtle but high-quality motion.

Prefer:

- AnimatedContainer
- Hero transitions
- AnimatedOpacity
- AnimatedPositioned
- TweenAnimationBuilder

Animations must feel intentional and smooth.

Avoid unnecessary complexity.

---

CODE QUALITY

Code must be:

- production ready
- well structured
- readable
- reusable

Split UI into widgets when needed.

Avoid extremely long widget trees.

Follow Flutter best practices.

---

OUTPUT FORMAT

Always provide:

1. A brief design concept explanation
2. Complete Flutter code
3. Any required packages
4. Notes about customization
